# Exchange Rate API

Exchange Rate API je aplikácia na získavanie a konverziu výmenných kurzov.

## Inštalácia a spustenie aplikacie

0. Vytvorit .env subor z .env.sample. Vlozit minimalne vlastny API kluc, podla potreby zmenit prihlasovacie udaje.

1. npm install
2. npm run docker:build
